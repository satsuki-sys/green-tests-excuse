# Green Tests, Nothing Works: The Excuse Contest

The entry is the excuse an AI agent gives when its unit tests are all green while nothing works: it tests exactly what the code does, and the code does nothing — perfectly. `main.py` writes that one line to `/output/entry.txt`.
